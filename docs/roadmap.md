## 0.5 现在做

**P0 已清空，M0–M4 闭环，M5 只差 `T4`（autorun），代码侧没有"必须先做"的项。** 剩下 4 条，分两类：

1. **真机验证（只能你验，不是写代码）**：`H7` 两个客户端各占一页互不打架。另外几件没进清单但同样要真机看一眼（[runbook.md](./runbook.md) 第 4 节就是按这个顺序写的）：侧边栏 `+` 发起任务、任务标签组与 chips、写审批卡的四个选项、左侧栏的技能预检与审计导出、断线后的重连状态、`submit-order` 经 MCP 跑通。
2. **确认要做、还没开工**：`T4`（autorun 技能检查）、`U6`/`U8`（真实登录验证、商店条目）。

页面上该有的都有了（技能面板、审计与导出）；剩下的不是等机器就是等真站点。

已经关闭的两个：`U5` 做成（扩展主动报 tab 事件，租约跟着走）；`C4` 站点笔记定为不做（见 [design.md](./design.md) §12）。

| 里程碑 | 内容 | 出口条件 |
|---|---|---|
| **M0 文档止血** | 旧文档退役、校验脚本、修已知不一致 | `pnpm docs:check` 进 CI；重复描述只剩一处 |

| **M2 MCP 能力面** | attach/detach、技能三工具、instructions | §7 的四条验收通过 |
| **M3 重复工作** | 断言、失败策略、批次授权、续跑 | 批量下单可无人值守一轮并汇总 |
| **M4 记忆与智能** | 知识召回、页面上下文刷新、站点笔记 | 失败时能拿到对应 SOP 段落 |
| **M5 收尾** | runbook、autorun、假扩展测试、工程清理 | 全绿 |
